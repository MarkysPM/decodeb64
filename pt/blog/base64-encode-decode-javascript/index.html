Base64 em JavaScript: btoa, atob e as armadilhas do Unicode

Novembro de 2026 · 7 min de leitura

O JavaScript oferece duas funções nativas para Base64, btoa() e atob(), e elas funcionam perfeitamente com ASCII. Os problemas começam quando o texto tem um emoji, uma letra acentuada fora do Latin-1 ou dados binários. Este guia mostra o que as funções realmente fazem, por que falham e os padrões que funcionam no navegador e no Node.js.

O básico: btoa e atob

Os nomes são históricos: btoa significa "binary to ASCII" (codificar) e atob significa "ASCII to binary" (decodificar).

btoa('Hello, World!');
// "SGVsbG8sIFdvcmxkIQ=="

atob('SGVsbG8sIFdvcmxkIQ==');
// "Hello, World!"

Ambas estão disponíveis em todos os navegadores modernos, em Web Workers e como globais nas versões atuais de Node.js, Deno e Bun.

O problema do Unicode

O detalhe-chave é que btoa() não recebe "texto". Ela recebe uma *string binária*, em que cada caractere deve ter um code point entre 0 e 255 e é tratado como um byte. Qualquer valor acima disso gera erro:

btoa('€');
// Uncaught InvalidCharacterError: String contains an invalid character

btoa('你好');
// Uncaught InvalidCharacterError

Caracteres como é (U+00E9) cabem na faixa 0–255, então btoa('café') parece funcionar, mas codifica o byte Latin-1 e não UTF-8. Outro sistema que decodifique o resultado como UTF-8 mostrará um caractere quebrado. O jeito seguro é converter a string para bytes UTF-8 primeiro e codificar esses bytes.

Codificando texto Unicode corretamente

Use TextEncoder para obter os bytes UTF-8, transforme-os em string binária e chame btoa():

function encodeBase64(text) {
  const bytes = new TextEncoder().encode(text);
  let binary = '';
  bytes.forEach(b => { binary += String.fromCharCode(b); });
  return btoa(binary);
}

encodeBase64('€');      // "4oKs"
encodeBase64('你好');   // "5L2g5aW9"

E o inverso com TextDecoder:

function decodeBase64(b64) {
  const binary = atob(b64);
  const bytes = Uint8Array.from(binary, c => c.charCodeAt(0));
  return new TextDecoder().decode(bytes);
}

decodeBase64('4oKs');   // "€"

Com entradas muito grandes, montar a string caractere por caractere é lento. Processe os bytes em blocos (por exemplo, 32.768 por vez com String.fromCharCode.apply) para evitar a lentidão e os limites da pilha de chamadas.

Node.js: use Buffer

No Node.js, o Buffer lida com UTF-8 e dados binários diretamente, sem gambiarras:

Buffer.from('€', 'utf8').toString('base64');
// "4oKs"

Buffer.from('4oKs', 'base64').toString('utf8');
// "€"

// Base64URL (Node.js 15.7+ and 14.18+)
Buffer.from('hello?>', 'utf8').toString('base64url');

O Buffer também é a ferramenta certa para arquivos, pois você lê o arquivo direto em um buffer e chama .toString('base64') sem criar uma string intermediária de bytes.

Dados binários no navegador

Para codificar um arquivo escolhido pelo usuário, FileReader.readAsDataURL() costuma ser o mais simples. O resultado é uma data URI e a parte Base64 é tudo o que vem depois da vírgula:

const reader = new FileReader();
reader.onload = () => {
  const dataUri = reader.result;           // "data:image/png;base64,iVBORw0..."
  const base64  = dataUri.split(',')[1];   // just the Base64 payload
};
reader.readAsDataURL(file);

Para o caminho inverso, transformando Base64 em um arquivo para download ou em uma URL de imagem, decodifique para um Uint8Array, envolva em um Blob e crie uma URL de objeto:

function base64ToBlob(b64, type = 'application/octet-stream') {
  const binary = atob(b64);
  const bytes = Uint8Array.from(binary, c => c.charCodeAt(0));
  return new Blob([bytes], { type });
}

const url = URL.createObjectURL(base64ToBlob(b64, 'image/png'));
img.src = url;

É isso que um conversor online de Base64 para imagem faz por baixo dos panos. Nossa ferramenta Base64 para Imagem roda inteira no seu navegador com essa mesma abordagem, então nada é enviado.

Base64URL em JavaScript

Os navegadores não têm um equivalente nativo de btoa para o alfabeto seguro para URL, então converta os caracteres você mesmo (veja Base64 vs Base64URL):

const toBase64Url = b64 =>
  b64.replace(/\+/g, '-').replace(/\//g, '_').replace(/=+$/, '');

const fromBase64Url = s => {
  let b64 = s.replace(/-/g, '+').replace(/_/g, '/');
  while (b64.length % 4) b64 += '=';
  return b64;
};

Tratamento de erros

atob() lança um InvalidCharacterError se a entrada contiver caracteres fora do alfabeto Base64. Ela ignora espaços em branco ASCII, então quebras de linha dentro de uma string longa não são problema, e as implementações atuais aceitam a falta de preenchimento desde que o tamanho não seja impossível (um tamanho 4n+1 nunca é válido). Sempre envolva a decodificação de entradas não confiáveis em try/catch:

function safeDecode(b64) {
  try {
    return atob(b64.trim());
  } catch (e) {
    return null;   // not valid Base64
  }
}

Referência rápida

  • Texto ASCII no navegador: btoa / atob.
  • Qualquer texto Unicode: TextEncoder ou TextDecoder em volta de btoa ou atob.
  • Node.js: Buffer.from(...).toString('base64'), que também aceita 'base64url'.
  • Arquivos no navegador: FileReader.readAsDataURL() para codificar, Blob mais URL.createObjectURL() para decodificar.
  • Nunca presuma que a string é válida: capture erros e use trim nos espaços.
