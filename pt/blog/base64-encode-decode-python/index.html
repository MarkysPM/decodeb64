Base64 em Python: codifique e decodifique strings, arquivos e URLs

Novembro de 2026 · 7 min de leitura

O Python traz tudo o que você precisa para Base64 no módulo padrão base64. O que confunde a maioria não é a API, e sim o sistema de tipos: o Base64 trabalha com *bytes*, enquanto quase todos os seus dados nascem como str. Entendendo essa fronteira, o resto é simples.

Codificando uma string

b64encode() recebe bytes e devolve bytes. Para codificar texto, primeiro converta-o em bytes e, para exibir o resultado, normalmente decodifique de volta para string:

import base64

text = "Hello, World!"
encoded = base64.b64encode(text.encode("utf-8"))
print(encoded)                    # b'SGVsbG8sIFdvcmxkIQ=='
print(encoded.decode("ascii"))    # SGVsbG8sIFdvcmxkIQ==

Passar uma str diretamente gera TypeError: a bytes-like object is required, not 'str'. Esse erro sempre significa que você esqueceu o passo .encode().

Decodificando uma string

b64decode() aceita bytes ou uma str somente ASCII e devolve bytes. Se o conteúdo for texto, decodifique os bytes com a codificação de caracteres correta:

raw = base64.b64decode("SGVsbG8sIFdvcmxkIQ==")
print(raw)                    # b'Hello, World!'
print(raw.decode("utf-8"))    # Hello, World!

Sempre informe a codificação explicitamente. Por exemplo, "héllo" é codificado como aMOpbGxv porque o é ocupa dois bytes em UTF-8. Se quem enviou usou outra codificação, como Latin-1 ou UTF-16, decodificar como UTF-8 vai gerar UnicodeDecodeError ou texto ilegível.

Validação estrita

Por padrão b64decode() é permissivo: descarta em silêncio os caracteres que não estão no alfabeto Base64. É cômodo com quebras de linha, mas pode esconder dados corrompidos. Passe validate=True para lançar binascii.Error em qualquer caractere inválido:

import binascii

try:
    data = base64.b64decode(user_input, validate=True)
except binascii.Error as e:
    print("Not valid Base64:", e)

Corrigindo "Incorrect padding"

O erro de Base64 mais comum em Python é binascii.Error: Incorrect padding. Significa que o tamanho da string não é múltiplo de quatro, o que costuma acontecer em valores Base64URL (como as partes de um JWT) cujos = foram removidos. Restaure-os antes de decodificar:

def b64decode_padded(s: str) -> bytes:
    s = s.strip()
    s += "=" * (-len(s) % 4)
    return base64.urlsafe_b64decode(s)

A expressão -len(s) % 4 dá o número de caracteres que faltam (0, 1, 2 ou 3). Um resto de 1 caractere nunca é Base64 válido, então uma string cujo tamanho é um a mais que um múltiplo de quatro está truncada ou corrompida e nenhum preenchimento resolve.

Base64 seguro para URL

Para tokens, identificadores e qualquer coisa que vá em uma URL, use as variantes URL-safe, que trocam + e / por - e _ (veja Base64 vs Base64URL):

token = base64.urlsafe_b64encode(b"\xfb\xff")
print(token)                      # b'-_8='

# Strip padding if the receiving system expects it
print(token.rstrip(b"=").decode()) # -_8

Note que urlsafe_b64encode() mantém o preenchimento. Remova-o você mesmo quando uma especificação como JWT exigir a forma sem preenchimento.

Codificando e decodificando arquivos

Abra os arquivos em modo binário ("rb" e "wb") para o Python não tentar interpretar o conteúdo como texto:

# File to Base64 string
with open("photo.png", "rb") as f:
    b64 = base64.b64encode(f.read()).decode("ascii")

# Base64 string back to file
with open("copy.png", "wb") as f:
    f.write(base64.b64decode(b64))

Montar uma data URI a partir de um arquivo exige só mais uma linha:

data_uri = f"data:image/png;base64,{b64}"

Para arquivos grandes, evite carregar tudo na memória. O módulo oferece base64.encode(input, output) e base64.decode(input, output), que fazem streaming entre dois objetos de arquivo binários e inserem uma quebra de linha a cada 76 caracteres ao codificar.

Decodificando uma data URI ou parte de um JWT

Remova o prefixo antes de decodificar, porque data:image/png;base64, não faz parte dos dados Base64:

def decode_data_uri(uri: str) -> bytes:
    header, _, payload = uri.partition(",")
    return base64.b64decode(payload)

Para espiar o payload de um JWT ao depurar (isto *não* verifica a assinatura):

import json

def jwt_payload(token: str) -> dict:
    payload = token.split(".")[1]
    payload += "=" * (-len(payload) % 4)
    return json.loads(base64.urlsafe_b64decode(payload))

Outras funções do módulo

  • b32encode() e b32decode(): Base32, útil para códigos legíveis como segredos TOTP.
  • b16encode() e b16decode(): hexadecimal simples.
  • a85encode() e b85encode(): codificações mais densas (cerca de 25 % de aumento em vez de 33 %), ao custo de um alfabeto maior.

Checklist quando algo falha

  • TypeError sobre bytes: chame .encode() antes de codificar.
  • Incorrect padding: a string foi truncada ou os = foram removidos; complete até um múltiplo de quatro.
  • Caracteres inválidos com validate=True: o valor provavelmente é Base64URL, contém espaços ou ainda tem o prefixo de uma data URI.
  • UnicodeDecodeError: os bytes decodificados não são texto UTF-8. Podem ser uma imagem, um blob compactado ou outra codificação.
