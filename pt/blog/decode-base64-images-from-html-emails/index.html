Como decodificar imagens Base64 de e-mails HTML e páginas web

Novembro de 2026 · 7 min de leitura

Às vezes a imagem de que você precisa não é um arquivo, e sim uma string enorme dentro de um e-mail ou do código-fonte de uma página. Newsletters, faturas, assinaturas e relatórios exportados costumam incorporar imagens em Base64. Recuperá-las é simples quando você sabe onde elas se escondem e qual método de incorporação foi usado.

Como as imagens vão parar dentro dos e-mails

Há duas formas comuns de colocar uma imagem em um e-mail HTML:

  • Data URI no HTML. A imagem faz parte do markup: <img src="data:image/png;base64,iVBORw0KGgo...">. Veja nosso guia de data URIs para a sintaxe. Muitos clientes de e-mail, incluindo o Gmail, não as exibem, então são mais raras em campanhas reais.
  • Parte anexa referenciada por cid:. O e-mail é uma mensagem MIME com várias partes. O HTML diz <img src="cid:logo123"> e uma parte separada com Content-ID: <logo123> e Content-Transfer-Encoding: base64 carrega os bytes da imagem. É a abordagem padrão para imagens embutidas em e-mail.

Ambas são Base64 por baixo, mas a extração é diferente.

Caso 1: uma data URI em HTML

Abra o código-fonte da página ou a visualização HTML do e-mail e encontre o atributo src="data:image/...". O jeito mais rápido de ver a imagem é copiar o valor inteiro, incluindo o prefixo data:image/png;base64,, e colá-lo no nosso conversor de Base64 para imagem. Ele mostra a prévia e permite baixar como PNG, JPG ou WebP sem enviar nada.

Para extrair todas as imagens de um arquivo grande automaticamente, use um script Python curto:

import base64, re

html = open("page.html", encoding="utf-8").read()
pattern = r'data:image/(png|jpeg|gif|webp);base64,([A-Za-z0-9+/=\s]+)'

for i, (ext, b64) in enumerate(re.findall(pattern, html)):
    data = base64.b64decode("".join(b64.split()))
    with open(f"image{i}.{ext}", "wb") as f:
        f.write(data)

O "".join(b64.split()) remove as quebras de linha que os sistemas de e-mail adicionam ao quebrar linhas longas. Para mais detalhes de Python, veja Base64 em Python.

Caso 2: anexos em um arquivo .eml

Salve a mensagem como .eml (a maioria dos clientes tem "Baixar" ou "Salvar como"). O pacote padrão email do Python entende MIME e faz a decodificação Base64 por você:

from email import policy
from email.parser import BytesParser

with open("message.eml", "rb") as f:
    msg = BytesParser(policy=policy.default).parse(f)

for n, part in enumerate(msg.walk()):
    if part.get_content_maintype() != "image":
        continue
    data = part.get_payload(decode=True)      # Base64 already decoded
    name = part.get_filename()
    if not name:
        cid = (part["Content-ID"] or f"image{n}").strip("<>")
        name = f"{cid}.{part.get_content_subtype()}"
    with open(name, "wb") as out:
        out.write(data)

Com get_payload(decode=True) a biblioteca trata o cabeçalho Content-Transfer-Encoding, então funciona tanto se a parte for Base64 quanto quoted-printable.

Se você só tem o texto bruto de uma parte MIME, copie o bloco que vem depois da linha em branco abaixo de Content-Transfer-Encoding: base64 e cole em decodeb64.com ou no conversor de imagens. Quebras de linha dentro do bloco não são problema.

Caso 3: pelo navegador

Em uma página web você pode dispensar o texto completamente:

  • Clique com o botão direito na imagem e escolha "Abrir imagem em nova guia", depois salve. Os navegadores decodificam data URIs por você.
  • Ou abra o DevTools, selecione o elemento <img> no painel Elements e copie o atributo src.
  • No Console, fetch(img.src).then(r => r.blob()) devolve os bytes decodificados como um Blob que você pode baixar.

Identifique o formato pelos primeiros caracteres

Se o prefixo da data URI estiver faltando, os primeiros caracteres do Base64 revelam o tipo de arquivo:

  • iVBORw0KGgo — PNG
  • /9j/ — JPEG
  • R0lGOD — GIF
  • UklGR — WebP (contêiner RIFF)
  • PHN2Zy ou PD94bWw — SVG ou texto XML
  • JVBERi0 — um PDF, não uma imagem

Nosso guia de decodificação de arquivos binários tem uma lista maior. Use a extensão correta ao salvar; caso contrário, o arquivo pode não abrir.

Imagens minúsculas geralmente são rastreadores

Se um e-mail contém uma imagem de 1×1 pixel, quase sempre é um pixel de rastreamento usado para detectar que a mensagem foi aberta. Decodificá-la mostrará um quadrado em branco ou transparente. Pixels em data URI não "ligam para casa", mas um pixel carregado de uma URL liga, e por isso muitos clientes bloqueiam imagens remotas por padrão.

Trate os resultados com segurança

  • SVG pode conter scripts. Não abra um SVG de um e-mail desconhecido diretamente no navegador e nunca o injete em uma página com innerHTML.
  • Não confie no tipo declarado. Uma parte rotulada como image/png pode ser outra coisa. Confira os primeiros bytes como mostrado acima.
  • Mensagens de phishing escondem conteúdo em Base64. Decodificar e visualizar na sua máquina é aceitável; clicar em links incorporados ou executar anexos, não.
  • Privacidade. Colar uma imagem privada em uma ferramenta online a envia, a menos que a ferramenta funcione localmente. O decodeb64.com decodifica no seu navegador, então os dados nunca saem do seu dispositivo.

Se a decodificação falhar

Os suspeitos de sempre são o prefixo data:...;base64, que ficou na string, espaços em branco ou entidades HTML dentro do valor (como &#43; em vez de +) e uma mensagem truncada ao ser salva. Por que a decodificação Base64 falha percorre uma lista curta para cada caso.
