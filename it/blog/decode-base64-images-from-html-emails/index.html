Come decodificare immagini Base64 da e-mail HTML e pagine web

Novembre 2026 · 7 min di lettura

A volte l'immagine che ti serve non è un file ma una stringa lunghissima dentro un'e-mail o nel codice sorgente di una pagina. Newsletter, fatture, firme e report esportati spesso incorporano le immagini come Base64. Recuperarle è semplice quando sai dove si nascondono e quale metodo di incorporamento è stato usato.

Come finiscono le immagini dentro le e-mail

Ci sono due modi comuni per inserire un'immagine in un'e-mail HTML:

  • Data URI nell'HTML. L'immagine fa parte del markup: <img src="data:image/png;base64,iVBORw0KGgo...">. Vedi la nostra guida ai data URI per la sintassi. Molti client di posta, Gmail compreso, non li mostrano, quindi sono più rari nelle campagne reali.
  • Parte allegata referenziata con cid:. L'e-mail è un messaggio MIME con più parti. L'HTML contiene <img src="cid:logo123"> e una parte separata con Content-ID: <logo123> e Content-Transfer-Encoding: base64 trasporta i byte dell'immagine. È l'approccio standard per le immagini inline nelle e-mail.

Entrambe sono Base64 sotto il cofano, ma si estraggono in modo diverso.

Caso 1: un data URI nell'HTML

Apri il sorgente della pagina o la vista HTML dell'e-mail e trova l'attributo src="data:image/...". Il modo più rapido per vedere l'immagine è copiare l'intero valore, compreso il prefisso data:image/png;base64,, e incollarlo nel nostro convertitore da Base64 a immagine. Mostra l'anteprima e permette di scaricarla come PNG, JPG o WebP senza caricare nulla.

Per estrarre automaticamente tutte le immagini da un file grande, usa un breve script Python:

import base64, re

html = open("page.html", encoding="utf-8").read()
pattern = r'data:image/(png|jpeg|gif|webp);base64,([A-Za-z0-9+/=\s]+)'

for i, (ext, b64) in enumerate(re.findall(pattern, html)):
    data = base64.b64decode("".join(b64.split()))
    with open(f"image{i}.{ext}", "wb") as f:
        f.write(data)

Il "".join(b64.split()) rimuove le interruzioni di riga che i sistemi di posta aggiungono quando spezzano le righe lunghe. Per altri dettagli su Python vedi Base64 in Python.

Caso 2: allegati in un file .eml

Salva il messaggio come .eml (la maggior parte dei client ha «Scarica» o «Salva con nome»). Il pacchetto standard email di Python comprende MIME ed esegue per te la decodifica Base64:

from email import policy
from email.parser import BytesParser

with open("message.eml", "rb") as f:
    msg = BytesParser(policy=policy.default).parse(f)

for n, part in enumerate(msg.walk()):
    if part.get_content_maintype() != "image":
        continue
    data = part.get_payload(decode=True)      # Base64 already decoded
    name = part.get_filename()
    if not name:
        cid = (part["Content-ID"] or f"image{n}").strip("<>")
        name = f"{cid}.{part.get_content_subtype()}"
    with open(name, "wb") as out:
        out.write(data)

Con get_payload(decode=True) la libreria gestisce l'intestazione Content-Transfer-Encoding, quindi funziona sia che la parte sia Base64 sia quoted-printable.

Se hai solo il testo grezzo di una parte MIME, copia il blocco che segue la riga vuota sotto Content-Transfer-Encoding: base64 e incollalo in decodeb64.com o nel convertitore di immagini. Le interruzioni di riga nel blocco non sono un problema.

Caso 3: dal browser

Su una pagina web puoi evitare del tutto il testo:

  • Clic destro sull'immagine, scegli «Apri immagine in una nuova scheda» e poi salvala. I browser decodificano i data URI per te.
  • Oppure apri DevTools, seleziona l'elemento <img> nel pannello Elements e copia l'attributo src.
  • Nella console, fetch(img.src).then(r => r.blob()) restituisce i byte decodificati come Blob che puoi scaricare.

Riconoscere il formato dai primi caratteri

Se manca il prefisso del data URI, i primi caratteri del Base64 rivelano il tipo di file:

  • iVBORw0KGgo — PNG
  • /9j/ — JPEG
  • R0lGOD — GIF
  • UklGR — WebP (contenitore RIFF)
  • PHN2Zy o PD94bWw — SVG o testo XML
  • JVBERi0 — un PDF, non un'immagine

La nostra guida alla decodifica di file binari ha un elenco più lungo. Usa l'estensione giusta quando salvi, altrimenti il file potrebbe non aprirsi.

Le immagini minuscole sono di solito tracker

Se un'e-mail contiene un'immagine di 1×1 pixel, è quasi sempre un pixel di tracciamento usato per rilevare che il messaggio è stato aperto. Decodificarla mostrerà un quadrato vuoto o trasparente. I pixel in data URI non contattano nessuno, mentre un pixel caricato da un URL sì, ed è per questo che molti client bloccano le immagini remote per impostazione predefinita.

Gestire i risultati in sicurezza

  • Un SVG può contenere script. Non aprire direttamente nel browser un SVG proveniente da un'e-mail sconosciuta e non iniettarlo mai in una pagina con innerHTML.
  • Non fidarti del tipo dichiarato. Una parte etichettata image/png può essere altro. Controlla i primi byte come mostrato sopra.
  • I messaggi di phishing nascondono contenuti in Base64. Decodificare e visualizzare sulla tua macchina va bene; cliccare su link incorporati o eseguire allegati no.
  • Privacy. Incollare un'immagine privata in uno strumento online la carica, a meno che lo strumento non funzioni in locale. decodeb64.com decodifica nel tuo browser, quindi i dati non lasciano mai il tuo dispositivo.

Se la decodifica fallisce

I sospetti abituali sono il prefisso data:...;base64, rimasto nella stringa, spazi bianchi o entità HTML dentro il valore (come &#43; invece di +) e un messaggio troncato al salvataggio. Perché la decodifica Base64 fallisce percorre una breve lista per ciascun caso.
