Python में Base64: स्ट्रिंग, फ़ाइल और URL को एन्कोड और डिकोड करें

नवंबर 2026 · 7 मिनट का पठन

Python में Base64 के लिए ज़रूरी हर चीज़ मानक base64 मॉड्यूल में मौजूद है। ज़्यादातर लोगों को भ्रम API से नहीं बल्कि टाइप सिस्टम से होता है: Base64 *bytes* पर काम करता है, जबकि आपका ज़्यादातर डेटा str के रूप में शुरू होता है। यह सीमा समझ में आ जाए तो बाकी आसान है।

स्ट्रिंग को एन्कोड करना

b64encode() bytes लेता है और bytes लौटाता है। टेक्स्ट को एन्कोड करने के लिए पहले उसे bytes में बदलना होता है, और परिणाम दिखाने के लिए आमतौर पर उसे वापस स्ट्रिंग में डिकोड करते हैं:

import base64

text = "Hello, World!"
encoded = base64.b64encode(text.encode("utf-8"))
print(encoded)                    # b'SGVsbG8sIFdvcmxkIQ=='
print(encoded.decode("ascii"))    # SGVsbG8sIFdvcmxkIQ==

सीधे str देने पर TypeError: a bytes-like object is required, not 'str' आता है। इस एरर का हमेशा यही मतलब होता है कि आप .encode() वाला चरण भूल गए।

स्ट्रिंग को डिकोड करना

b64decode() bytes या केवल-ASCII str स्वीकार करता है और bytes लौटाता है। यदि सामग्री टेक्स्ट है, तो bytes को सही कैरेक्टर एन्कोडिंग से डिकोड करें:

raw = base64.b64decode("SGVsbG8sIFdvcmxkIQ==")
print(raw)                    # b'Hello, World!'
print(raw.decode("utf-8"))    # Hello, World!

एन्कोडिंग हमेशा स्पष्ट रूप से बताएँ। उदाहरण के लिए, "héllo" का एन्कोड aMOpbGxv होता है क्योंकि é UTF-8 में दो बाइट लेता है। यदि भेजने वाले ने Latin-1 या UTF-16 जैसी कोई और एन्कोडिंग इस्तेमाल की थी, तो UTF-8 के रूप में डिकोड करने पर UnicodeDecodeError आएगा या टेक्स्ट अपठनीय बनेगा।

सख़्त सत्यापन

डिफ़ॉल्ट रूप से b64decode() उदार है: वह Base64 वर्णमाला में न आने वाले अक्षरों को चुपचाप छोड़ देता है। नई पंक्तियों वाली स्ट्रिंग के लिए यह सुविधाजनक है, लेकिन यह खराब डेटा को छिपा सकता है। किसी भी अमान्य अक्षर पर binascii.Error पाने के लिए validate=True दें:

import binascii

try:
    data = base64.b64decode(user_input, validate=True)
except binascii.Error as e:
    print("Not valid Base64:", e)

"Incorrect padding" को ठीक करना

Python में सबसे आम Base64 एरर binascii.Error: Incorrect padding है। इसका मतलब है कि स्ट्रिंग की लंबाई चार का गुणज नहीं है, जो अक्सर उन Base64URL मानों (जैसे JWT के हिस्से) के साथ होता है जिनसे = हटा दिए गए हों। डिकोड करने से पहले उन्हें वापस जोड़ें:

def b64decode_padded(s: str) -> bytes:
    s = s.strip()
    s += "=" * (-len(s) % 4)
    return base64.urlsafe_b64decode(s)

व्यंजक -len(s) % 4 गायब अक्षरों की संख्या (0, 1, 2 या 3) देता है। 1 अक्षर का शेष कभी मान्य Base64 नहीं होता, इसलिए जिस स्ट्रिंग की लंबाई चार के गुणज से एक अधिक है वह कटी हुई या खराब है और कोई पैडिंग उसे ठीक नहीं करेगी।

URL-सुरक्षित Base64

टोकन, आइडेंटिफ़ायर और URL में जाने वाली हर चीज़ के लिए URL-सुरक्षित रूपों का उपयोग करें, जो + और / को - और _ से बदल देते हैं (Base64 बनाम Base64URL देखें):

token = base64.urlsafe_b64encode(b"\xfb\xff")
print(token)                      # b'-_8='

# Strip padding if the receiving system expects it
print(token.rstrip(b"=").decode()) # -_8

ध्यान दें कि urlsafe_b64encode() पैडिंग बनाए रखता है। जब JWT जैसा कोई विनिर्देश बिना पैडिंग का रूप माँगे तो उसे खुद हटाएँ।

फ़ाइलों को एन्कोड और डिकोड करना

फ़ाइलों को बाइनरी मोड ("rb" और "wb") में खोलें ताकि Python सामग्री को टेक्स्ट की तरह समझने की कोशिश न करे:

# File to Base64 string
with open("photo.png", "rb") as f:
    b64 = base64.b64encode(f.read()).decode("ascii")

# Base64 string back to file
with open("copy.png", "wb") as f:
    f.write(base64.b64decode(b64))

फ़ाइल से डेटा URI बनाने के लिए बस एक पंक्ति और चाहिए:

data_uri = f"data:image/png;base64,{b64}"

बड़ी फ़ाइलों के लिए सब कुछ मेमोरी में लोड करने से बचें। मॉड्यूल base64.encode(input, output) और base64.decode(input, output) देता है, जो दो बाइनरी फ़ाइल ऑब्जेक्ट के बीच स्ट्रीम करते हैं और एन्कोड करते समय हर 76 अक्षर पर नई पंक्ति डालते हैं।

डेटा URI या JWT के हिस्से को डिकोड करना

डिकोड करने से पहले प्रीफ़िक्स हटाएँ, क्योंकि data:image/png;base64, Base64 डेटा का हिस्सा नहीं है:

def decode_data_uri(uri: str) -> bytes:
    header, _, payload = uri.partition(",")
    return base64.b64decode(payload)

डिबगिंग के दौरान JWT का पेलोड देखने के लिए (यह सिग्नेचर को सत्यापित *नहीं* करता):

import json

def jwt_payload(token: str) -> dict:
    payload = token.split(".")[1]
    payload += "=" * (-len(payload) % 4)
    return json.loads(base64.urlsafe_b64decode(payload))

किस पर सुरक्षित रूप से भरोसा किया जा सकता है, इसके बारे में हमारी JWT डिकोडिंग गाइड में पढ़ें।

मॉड्यूल के अन्य फ़ंक्शन

  • b32encode() और b32decode(): Base32, TOTP सीक्रेट जैसे मानव-पठनीय कोड के लिए उपयोगी।
  • b16encode() और b16decode(): सादा हेक्साडेसिमल।
  • a85encode() और b85encode(): अधिक सघन एन्कोडिंग (33% की जगह लगभग 25% वृद्धि), बड़ी वर्णमाला की कीमत पर।

कुछ विफल होने पर चेकलिस्ट

  • bytes से जुड़ा TypeError: एन्कोड करने से पहले .encode() कॉल करें।
  • Incorrect padding: स्ट्रिंग कट गई है या = हटा दिए गए हैं; चार के गुणज तक पैड करें।
  • validate=True के साथ अमान्य अक्षर: मान शायद Base64URL है, उसमें खाली स्थान है, या उस पर अभी भी डेटा URI प्रीफ़िक्स है।
  • UnicodeDecodeError: डिकोड किए गए बाइट UTF-8 टेक्स्ट नहीं हैं। वे इमेज, संपीड़ित ब्लॉब या कोई और एन्कोडिंग हो सकते हैं।
