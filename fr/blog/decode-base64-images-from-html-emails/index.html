Comment décoder des images Base64 depuis des e-mails HTML et des pages web

Novembre 2026 · 7 min de lecture

Parfois, l'image dont vous avez besoin n'est pas un fichier mais une chaîne interminable à l'intérieur d'un e-mail ou du code source d'une page. Newsletters, factures, signatures et rapports exportés intègrent souvent leurs images en Base64. Les récupérer est simple quand on sait où elles se cachent et quelle méthode d'intégration a été utilisée.

Comment les images se retrouvent dans les e-mails

Il existe deux façons courantes d'insérer une image dans un e-mail HTML :

  • Data URI dans le HTML. L'image fait partie du balisage : <img src="data:image/png;base64,iVBORw0KGgo...">. Voir notre guide des data URI pour la syntaxe. De nombreux clients de messagerie, dont Gmail, ne les affichent pas ; elles sont donc plus rares dans les vraies campagnes.
  • Partie jointe référencée par cid:. L'e-mail est un message MIME à plusieurs parties. Le HTML contient <img src="cid:logo123"> et une partie distincte avec Content-ID: <logo123> et Content-Transfer-Encoding: base64 transporte les octets de l'image. C'est l'approche standard pour les images incorporées dans un e-mail.

Les deux sont du Base64 en coulisses, mais on les extrait différemment.

Cas 1 : une data URI dans du HTML

Ouvrez le code source de la page ou la vue HTML de l'e-mail et repérez l'attribut src="data:image/...". Le moyen le plus rapide de voir l'image est de copier la valeur entière, préfixe data:image/png;base64, compris, et de la coller dans notre convertisseur Base64 vers image. Il affiche l'aperçu et permet de télécharger en PNG, JPG ou WebP sans rien envoyer.

Pour extraire automatiquement toutes les images d'un gros fichier, utilisez un court script Python :

import base64, re

html = open("page.html", encoding="utf-8").read()
pattern = r'data:image/(png|jpeg|gif|webp);base64,([A-Za-z0-9+/=\s]+)'

for i, (ext, b64) in enumerate(re.findall(pattern, html)):
    data = base64.b64decode("".join(b64.split()))
    with open(f"image{i}.{ext}", "wb") as f:
        f.write(data)

Le "".join(b64.split()) supprime les retours à la ligne que les systèmes de messagerie ajoutent en coupant les longues lignes. Pour plus de détails sur Python, voir Base64 en Python.

Cas 2 : pièces jointes dans un fichier .eml

Enregistrez le message en .eml (la plupart des clients proposent « Télécharger » ou « Enregistrer sous »). Le paquet standard email de Python comprend MIME et effectue le décodage Base64 pour vous :

from email import policy
from email.parser import BytesParser

with open("message.eml", "rb") as f:
    msg = BytesParser(policy=policy.default).parse(f)

for n, part in enumerate(msg.walk()):
    if part.get_content_maintype() != "image":
        continue
    data = part.get_payload(decode=True)      # Base64 already decoded
    name = part.get_filename()
    if not name:
        cid = (part["Content-ID"] or f"image{n}").strip("<>")
        name = f"{cid}.{part.get_content_subtype()}"
    with open(name, "wb") as out:
        out.write(data)

Avec get_payload(decode=True), la bibliothèque gère l'en-tête Content-Transfer-Encoding ; cela fonctionne donc que la partie soit en Base64 ou en quoted-printable.

Si vous n'avez que le texte brut d'une partie MIME, copiez le bloc qui suit la ligne vide sous Content-Transfer-Encoding: base64 et collez-le dans decodeb64.com ou dans le convertisseur d'images. Les retours à la ligne dans le bloc ne posent pas de problème.

Cas 3 : depuis le navigateur

Sur une page web, vous pouvez vous passer complètement du texte :

  • Faites un clic droit sur l'image, choisissez « Ouvrir l'image dans un nouvel onglet », puis enregistrez-la. Les navigateurs décodent les data URI pour vous.
  • Ou ouvrez les DevTools, sélectionnez l'élément <img> dans le panneau Elements et copiez l'attribut src.
  • Dans la console, fetch(img.src).then(r => r.blob()) renvoie les octets décodés sous forme de Blob que vous pouvez télécharger.

Identifier le format grâce aux premiers caractères

Si le préfixe de la data URI manque, les premiers caractères du Base64 révèlent le type de fichier :

  • iVBORw0KGgo — PNG
  • /9j/ — JPEG
  • R0lGOD — GIF
  • UklGR — WebP (conteneur RIFF)
  • PHN2Zy ou PD94bWw — SVG ou texte XML
  • JVBERi0 — un PDF, pas une image

Notre guide sur le décodage de fichiers binaires propose une liste plus longue. Utilisez la bonne extension à l'enregistrement, sinon le fichier risque de ne pas s'ouvrir.

Les images minuscules sont généralement des traceurs

Si un e-mail contient une image de 1×1 pixel, c'est presque toujours un pixel espion servant à détecter l'ouverture du message. Le décoder affichera un carré vide ou transparent. Les pixels en data URI ne contactent aucun serveur, contrairement à un pixel chargé depuis une URL, ce qui explique que beaucoup de clients bloquent les images distantes par défaut.

Manipuler les résultats en toute sécurité

  • Un SVG peut contenir des scripts. N'ouvrez pas directement dans le navigateur un SVG provenant d'un e-mail inconnu et ne l'injectez jamais dans une page avec innerHTML.
  • Ne vous fiez pas au type déclaré. Une partie étiquetée image/png peut être autre chose. Vérifiez les premiers octets comme indiqué plus haut.
  • Les messages d'hameçonnage cachent du contenu en Base64. Décoder et visualiser sur votre propre machine est acceptable ; cliquer sur des liens intégrés ou exécuter des pièces jointes ne l'est pas.
  • Confidentialité. Coller une image privée dans un outil en ligne la téléverse, sauf si l'outil fonctionne en local. decodeb64.com décode dans votre navigateur ; les données ne quittent donc jamais votre appareil.

Si le décodage échoue

Les suspects habituels sont le préfixe data:...;base64, resté dans la chaîne, des espaces blancs ou entités HTML dans la valeur (comme &#43; au lieu de +) et un message tronqué à l'enregistrement. Pourquoi le décodage Base64 échoue passe en revue une courte liste pour chaque cas.
