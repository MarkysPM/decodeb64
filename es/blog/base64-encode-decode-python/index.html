Base64 en Python: codifica y decodifica cadenas, archivos y URLs

Noviembre de 2026 · 7 min de lectura

Python incluye todo lo necesario para Base64 en el módulo estándar base64. Lo que confunde a la mayoría no es la API sino el sistema de tipos: Base64 trabaja con *bytes*, mientras que casi todos tus datos empiezan como str. Una vez entiendes esa frontera, el resto es sencillo.

Codificar una cadena

b64encode() recibe bytes y devuelve bytes. Para codificar texto primero debes convertirlo en bytes y, para mostrar el resultado, normalmente lo decodificas de nuevo a cadena:

import base64

text = "Hello, World!"
encoded = base64.b64encode(text.encode("utf-8"))
print(encoded)                    # b'SGVsbG8sIFdvcmxkIQ=='
print(encoded.decode("ascii"))    # SGVsbG8sIFdvcmxkIQ==

Pasar un str directamente lanza TypeError: a bytes-like object is required, not 'str'. Ese error siempre significa que olvidaste el paso .encode().

Decodificar una cadena

b64decode() acepta bytes o un str solo ASCII y devuelve bytes. Si el contenido es texto, decodifica los bytes con la codificación de caracteres correcta:

raw = base64.b64decode("SGVsbG8sIFdvcmxkIQ==")
print(raw)                    # b'Hello, World!'
print(raw.decode("utf-8"))    # Hello, World!

Indica siempre la codificación explícitamente. Por ejemplo, "héllo" se codifica como aMOpbGxv porque la é ocupa dos bytes en UTF-8. Si el emisor usó otra codificación, como Latin-1 o UTF-16, decodificar como UTF-8 lanzará UnicodeDecodeError o producirá texto ilegible.

Validación estricta

Por defecto b64decode() es permisivo: descarta en silencio los caracteres que no están en el alfabeto Base64. Es cómodo con saltos de línea, pero puede ocultar datos corruptos. Pasa validate=True para que lance binascii.Error ante cualquier carácter inválido:

import binascii

try:
    data = base64.b64decode(user_input, validate=True)
except binascii.Error as e:
    print("Not valid Base64:", e)

Corregir "Incorrect padding"

El error de Base64 más común en Python es binascii.Error: Incorrect padding. Significa que la longitud de la cadena no es múltiplo de cuatro, algo habitual en valores Base64URL (como las partes de un JWT) a los que se les han quitado los =. Restáuralos antes de decodificar:

def b64decode_padded(s: str) -> bytes:
    s = s.strip()
    s += "=" * (-len(s) % 4)
    return base64.urlsafe_b64decode(s)

La expresión -len(s) % 4 da el número de caracteres que faltan (0, 1, 2 o 3). Un resto de 1 carácter nunca es Base64 válido, así que una cadena cuya longitud es uno más que un múltiplo de cuatro está truncada o corrupta y ningún relleno la arreglará.

Base64 seguro para URL

Para tokens, identificadores y todo lo que vaya en una URL, usa las variantes URL-safe, que sustituyen + y / por - y _ (consulta Base64 vs Base64URL):

token = base64.urlsafe_b64encode(b"\xfb\xff")
print(token)                      # b'-_8='

# Strip padding if the receiving system expects it
print(token.rstrip(b"=").decode()) # -_8

Ten en cuenta que urlsafe_b64encode() conserva el relleno. Quítalo tú cuando una especificación como JWT exija la forma sin relleno.

Codificar y decodificar archivos

Abre los archivos en modo binario ("rb" y "wb") para que Python no intente interpretar el contenido como texto:

# File to Base64 string
with open("photo.png", "rb") as f:
    b64 = base64.b64encode(f.read()).decode("ascii")

# Base64 string back to file
with open("copy.png", "wb") as f:
    f.write(base64.b64decode(b64))

Construir una data URI a partir de un archivo requiere una línea más:

data_uri = f"data:image/png;base64,{b64}"

Con archivos grandes, evita cargarlo todo en memoria. El módulo ofrece base64.encode(input, output) y base64.decode(input, output), que transmiten entre dos objetos de archivo binarios e insertan un salto de línea cada 76 caracteres al codificar.

Decodificar una data URI o una parte de un JWT

Quita el prefijo antes de decodificar, porque data:image/png;base64, no forma parte de los datos Base64:

def decode_data_uri(uri: str) -> bytes:
    header, _, payload = uri.partition(",")
    return base64.b64decode(payload)

Para echar un vistazo al payload de un JWT al depurar (esto *no* verifica la firma):

import json

def jwt_payload(token: str) -> dict:
    payload = token.split(".")[1]
    payload += "=" * (-len(payload) % 4)
    return json.loads(base64.urlsafe_b64decode(payload))

Otras funciones del módulo

  • b32encode() y b32decode(): Base32, útil para códigos legibles como los secretos TOTP.
  • b16encode() y b16decode(): hexadecimal simple.
  • a85encode() y b85encode(): codificaciones más densas (cerca de un 25 % de aumento en lugar del 33 %), a costa de un alfabeto más grande.

Lista de comprobación cuando algo falla

  • TypeError sobre bytes: llama a .encode() antes de codificar.
  • Incorrect padding: la cadena está truncada o se quitaron los =; rellena hasta un múltiplo de cuatro.
  • Caracteres inválidos con validate=True: el valor probablemente es Base64URL, contiene espacios o conserva el prefijo de una data URI.
  • UnicodeDecodeError: los bytes decodificados no son texto UTF-8. Pueden ser una imagen, un blob comprimido u otra codificación.
