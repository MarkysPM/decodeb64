Cómo decodificar imágenes Base64 de correos HTML y páginas web

Noviembre de 2026 · 7 min de lectura

A veces la imagen que necesitas no es un archivo sino una cadena larguísima dentro de un correo o del código fuente de una página. Los boletines, facturas, firmas e informes exportados suelen incrustar imágenes como Base64. Recuperarlas es sencillo cuando sabes dónde se esconden y qué método de incrustación se usó.

Cómo acaban las imágenes dentro de los correos

Hay dos formas habituales de poner una imagen en un correo HTML:

  • Data URI en el HTML. La imagen forma parte del marcado: <img src="data:image/png;base64,iVBORw0KGgo...">. Consulta nuestra guía de data URIs para ver la sintaxis. Muchos clientes de correo, incluido Gmail, no las muestran, por lo que son menos frecuentes en campañas reales.
  • Parte adjunta referenciada con cid:. El correo es un mensaje MIME con varias partes. El HTML dice <img src="cid:logo123"> y una parte aparte con Content-ID: <logo123> y Content-Transfer-Encoding: base64 lleva los bytes de la imagen. Es el método estándar para imágenes en línea en el correo.

Ambas son Base64 por debajo, pero se extraen de forma distinta.

Caso 1: una data URI en HTML

Abre el código fuente de la página o la vista HTML del correo y busca el atributo src="data:image/...". La forma más rápida de ver la imagen es copiar el valor entero, incluido el prefijo data:image/png;base64,, y pegarlo en nuestro conversor de Base64 a imagen. Muestra la vista previa y permite descargarla como PNG, JPG o WebP sin subir nada.

Para extraer todas las imágenes de un archivo grande automáticamente, usa un script corto de Python:

import base64, re

html = open("page.html", encoding="utf-8").read()
pattern = r'data:image/(png|jpeg|gif|webp);base64,([A-Za-z0-9+/=\s]+)'

for i, (ext, b64) in enumerate(re.findall(pattern, html)):
    data = base64.b64decode("".join(b64.split()))
    with open(f"image{i}.{ext}", "wb") as f:
        f.write(data)

El "".join(b64.split()) elimina los saltos de línea que añaden los sistemas de correo al ajustar líneas largas. Para más detalles de Python, consulta Base64 en Python.

Caso 2: adjuntos en un archivo .eml

Guarda el mensaje como .eml (la mayoría de los clientes tienen "Descargar" o "Guardar como"). El paquete estándar email de Python entiende MIME y hace por ti la decodificación Base64:

from email import policy
from email.parser import BytesParser

with open("message.eml", "rb") as f:
    msg = BytesParser(policy=policy.default).parse(f)

for n, part in enumerate(msg.walk()):
    if part.get_content_maintype() != "image":
        continue
    data = part.get_payload(decode=True)      # Base64 already decoded
    name = part.get_filename()
    if not name:
        cid = (part["Content-ID"] or f"image{n}").strip("<>")
        name = f"{cid}.{part.get_content_subtype()}"
    with open(name, "wb") as out:
        out.write(data)

Con get_payload(decode=True) la biblioteca gestiona la cabecera Content-Transfer-Encoding, así que funciona tanto si la parte es Base64 como quoted-printable.

Si solo tienes el texto sin procesar de una parte MIME, copia el bloque que sigue a la línea en blanco bajo Content-Transfer-Encoding: base64 y pégalo en decodeb64.com o en el conversor de imágenes. Los saltos de línea dentro del bloque no son un problema.

Caso 3: desde el navegador

En una página web puedes olvidarte del texto por completo:

  • Haz clic derecho en la imagen y elige "Abrir imagen en una pestaña nueva", y luego guárdala. Los navegadores decodifican las data URIs por ti.
  • O abre DevTools, selecciona el elemento <img> en el panel Elements y copia el atributo src.
  • En la consola, fetch(img.src).then(r => r.blob()) devuelve los bytes decodificados como un Blob que puedes descargar.

Identifica el formato por los primeros caracteres

Si falta el prefijo de la data URI, los primeros caracteres del Base64 revelan el tipo de archivo:

  • iVBORw0KGgo — PNG
  • /9j/ — JPEG
  • R0lGOD — GIF
  • UklGR — WebP (contenedor RIFF)
  • PHN2Zy o PD94bWw — SVG o texto XML
  • JVBERi0 — un PDF, no una imagen

Nuestra guía de decodificación de archivos binarios tiene una lista más larga. Usa la extensión correcta al guardar; si no, puede que el archivo no se abra.

Las imágenes diminutas suelen ser rastreadores

Si un correo contiene una imagen de 1×1 píxel, casi siempre es un píxel de seguimiento para detectar que el mensaje se abrió. Al decodificarla verás un cuadrado vacío o transparente. Los píxeles en data URI no se conectan a ningún sitio, pero un píxel cargado desde una URL sí, por eso muchos clientes bloquean las imágenes remotas de forma predeterminada.

Maneja los resultados con seguridad

  • Un SVG puede contener scripts. No abras un SVG de un correo desconocido directamente en el navegador y no lo inyectes nunca en una página con innerHTML.
  • No te fíes del tipo declarado. Una parte etiquetada como image/png puede ser otra cosa. Comprueba los primeros bytes como se explica arriba.
  • El phishing esconde contenido en Base64. Decodificar y ver en tu propio equipo está bien; hacer clic en enlaces incrustados o ejecutar archivos adjuntos, no.
  • Privacidad. Pegar una imagen privada en una herramienta online la sube a menos que la herramienta funcione en local. decodeb64.com decodifica en tu navegador, así que los datos nunca salen de tu dispositivo.

Si la decodificación falla

Los sospechosos habituales son el prefijo data:...;base64, que se quedó en la cadena, espacios o entidades HTML dentro del valor (como &#43; en lugar de +) y un mensaje truncado al guardarse. Por qué falla la decodificación Base64 repasa una lista corta para cada caso.
