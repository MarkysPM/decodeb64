如何从 HTML 邮件和网页中解码 Base64 图片

2026年11月 · 7 分钟阅读

有时你需要的图片不是一个文件，而是藏在邮件或网页源码里的一长串字符。新闻邮件、发票、签名和导出的报告常把图片以 Base64 嵌入。只要知道它们藏在哪里、用的是哪种嵌入方式，把它们取出来很简单。

图片是怎样进入邮件的

在 HTML 邮件中放入图片有两种常见方式：

  • HTML 中的 Data URI。图片是标记的一部分：<img src="data:image/png;base64,iVBORw0KGgo...">。语法见我们的 Data URI 指南。包括 Gmail 在内的许多邮件客户端不显示这种图片，所以在真实的营销邮件中较少见。
  • 通过 cid: 引用的附件部分。邮件是由多个部分组成的 MIME 消息。HTML 写着 <img src="cid:logo123">，另一个带有 Content-ID: <logo123> 和 Content-Transfer-Encoding: base64 的部分携带图片字节。这是邮件内嵌图片的标准做法。

两者底层都是 Base64，但提取方式不同。

情形 1：HTML 中的 Data URI

打开页面源码或邮件的 HTML 视图，找到 src="data:image/..." 属性。最快的看图方式是复制完整的值（包括 data:image/png;base64, 前缀），粘贴到我们的 Base64 转图片转换器。它会预览图片，并允许你下载为 PNG、JPG 或 WebP，且不会上传任何内容。

要自动从大文件中提取所有图片，可以使用一个简短的 Python 脚本：

import base64, re

html = open("page.html", encoding="utf-8").read()
pattern = r'data:image/(png|jpeg|gif|webp);base64,([A-Za-z0-9+/=\s]+)'

for i, (ext, b64) in enumerate(re.findall(pattern, html)):
    data = base64.b64decode("".join(b64.split()))
    with open(f"image{i}.{ext}", "wb") as f:
        f.write(data)

"".join(b64.split()) 会去掉邮件系统在折行时加入的换行。更多 Python 细节见 Python 中的 Base64。

情形 2：.eml 文件中的附件

把邮件保存为 .eml（大多数客户端都有“下载”或“另存为”）。Python 标准库的 email 包理解 MIME，并会替你完成 Base64 解码：

from email import policy
from email.parser import BytesParser

with open("message.eml", "rb") as f:
    msg = BytesParser(policy=policy.default).parse(f)

for n, part in enumerate(msg.walk()):
    if part.get_content_maintype() != "image":
        continue
    data = part.get_payload(decode=True)      # Base64 already decoded
    name = part.get_filename()
    if not name:
        cid = (part["Content-ID"] or f"image{n}").strip("<>")
        name = f"{cid}.{part.get_content_subtype()}"
    with open(name, "wb") as out:
        out.write(data)

使用 get_payload(decode=True)，库会处理 Content-Transfer-Encoding 头，因此无论该部分是 Base64 还是 quoted-printable 都能正常工作。

如果你只有某个 MIME 部分的原始文本，复制 Content-Transfer-Encoding: base64 下面空行之后的那一块，粘贴到 decodeb64.com 或图片转换器即可。块内的换行不是问题。

情形 3：通过浏览器

在网页上，你可以完全绕过文本：

  • 右键点击图片，选择“在新标签页中打开图片”，然后保存。浏览器会替你解码 Data URI。
  • 或者打开开发者工具，在 Elements 面板中选中 <img> 元素并复制 src 属性。
  • 在控制台中，fetch(img.src).then(r => r.blob()) 会把解码后的字节作为可下载的 Blob 返回。

通过开头字符识别格式

如果缺少 Data URI 前缀，Base64 的开头几个字符就能透露文件类型：

  • iVBORw0KGgo — PNG
  • /9j/ — JPEG
  • R0lGOD — GIF
  • UklGR — WebP（RIFF 容器）
  • PHN2Zy 或 PD94bWw — SVG 或 XML 文本
  • JVBERi0 — PDF，不是图片

我们的解码二进制文件指南有更完整的列表。保存时请使用正确的扩展名，否则文件可能无法打开。

极小的图片通常是追踪器

如果邮件中含有一个 1×1 像素的图片，几乎都是用来检测邮件是否被打开的追踪像素。解码后会看到空白或透明的方块。以 Data URI 形式存在的像素不会联系外部服务器，但从 URL 加载的像素会，这就是许多客户端默认屏蔽远程图片的原因。

安全处理结果

  • SVG 可能含有脚本。不要直接在浏览器中打开来自陌生邮件的 SVG，也不要用 innerHTML 把它注入页面。
  • 不要轻信声明的类型。标注为 image/png 的部分可能是别的东西。请按上文所述检查前几个字节。
  • 钓鱼邮件会把内容藏在 Base64 里。在自己的机器上解码和查看是可以的；点击嵌入的链接或运行附件则不行。
  • 隐私。把私人图片粘贴到在线工具中，除非该工具在本地运行，否则就会上传。decodeb64.com 在你的浏览器中解码，数据不会离开你的设备。

如果解码失败

常见的嫌疑包括：字符串里残留的 data:...;base64, 前缀、值内的空白或 HTML 实体（例如 &#43; 而不是 +），以及保存时被截断的邮件。Base64 解码为何失败针对每种情况给出了简短的检查清单。
